     4→// ║                                                                    ║
     5→// ║  Rules encoded here (per engineering directive):                   ║
     6→// ║  • All money is integer minor units (BigInt) — never floats        ║
     7→// ║  • Double-entry ledger: every transaction balances debits=credits  ║
     8→// ║  • Posted ledger records are immutable — corrections via reversal  ║
     9→// ║  • Every money-changing operation carries an idempotency key       ║
    10→// ║  • SQLite build uses String status fields; domain unions in        ║
    11→// ║    @novera/domain enforce legal state transitions in TypeScript    ║
    12→// ║  • Production target: PostgreSQL 18 (same model, native enums)     ║
    13→// ╚══════════════════════════════════════════════════════════════════╝
